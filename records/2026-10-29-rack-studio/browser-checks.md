# 真实浏览器验收

目标始终为 localhost:5193 的本地开发副本。

1. 打开 Northern DC Campus，Rack layout 选择 32 柜演示。点阵背景、实际 32/236/8 统计、全房面积与局部设备区标签、缩略图、禁放区正常显示。
2. “展开工作台”显示大画布与右侧 Inspector；编辑/保存/放弃按钮一并可用。窄视口详情在下方，宽视口并排。
3. Edit layout 后原生指针拖动 D08 到空白区：位置更新到共享草稿，后端检查期间保存禁用，检查完成后 Save layout 可用。没有执行保存。
4. 再将 D08 拖到 C07：真实检查返回两条 CLEARANCE_RACK_CONFLICT 与 RACK_PAIR_OVERLAP，Save layout 保持禁用；图面红色冲突。之后 Discard changes。
5. A01 恢复保存坐标 48.25,40.721m，显示位置锁定、旋转按钮禁用；实际 13/42U、9.3/12kW、4 台设备。点 GPU 服务器显示 4U/80kg/3kW/U1–4/model v1；点 ToR 显示 1U/10kg/0.3kW/U13/model v1。
6. 待上架入口只列 8 台待分配设备，包含超高和规格未知的例子；已安装设备不混入。
7. 已放弃全部验收草稿，普通 GET 重读确认示例 v2 和 D08 原坐标不变；未修改源方案或保存新候选。

工具跨调用有时退出全屏，因此需要重新展开；未把全屏维持状态当作持久化行为，也未使用工具修改隐藏浏览器状态。最终保留可查看的工作台。
